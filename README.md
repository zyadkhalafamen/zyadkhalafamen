# 📌 Featured Projects

## 👁️ Computer Vision

### 🔩 Clamp Detection & Fixed-ID Tracking
Computer vision system for detecting and tracking clamps using **YOLO11m and BoT-SORT**, with additional motion modeling and logical ID assignment for stable fixed IDs.

**Key technologies:** Python • YOLO11m • BoT-SORT • OpenCV • Object Tracking

[View Project](https://github.com/zyadkhalafamen/clamp-detection-tracking)

---

### 🔩 Nut Detection, Tracking & Counting
Classical computer vision pipeline for detecting, separating, tracking, and counting metallic nuts on a conveyor.

The system combines **image segmentation, Watershed separation, motion prediction, Hungarian assignment, and line-crossing logic**.

**Key technologies:** Python • OpenCV • Watershed • SciPy • Scikit-image

[View Project](https://github.com/zyadkhalafamen/nut-detection-tracking-counting)

---

## 💻 Embedded Systems & Robotics

### 🚗 STM32F401 Smart Garage Access Control System
Embedded smart garage system developed using the **STM32F401CCU6** with a modular firmware architecture.

Features include **password authentication, keypad input, LCD interface, servo-based gate control, vehicle counting, emergency mode, lockout protection, and a non-blocking gate state machine**.

**Key technologies:** STM32 • Embedded C • STM32CubeIDE • State Machines • Custom Drivers

[View Project](https://github.com/zyadkhalafamen/stm32f401-smart-garage)

---

### 🤖 Arduino Bluetooth & Ultrasonic Robotic Car
Arduino Mega robotic car featuring **Bluetooth/Serial control, dual ultrasonic obstacle protection, independent motor control, and Proteus simulation**.

**Key technologies:** Arduino Mega • C++ • Ultrasonic Sensors • L293D • Motor Control • Proteus

[View Project](https://github.com/zyadkhalafamen/arduino-bluetooth-ultrasonic-car)

---

## 🏭 Industrial Automation

### 📦 PLC-Based Height Sorting System
Automated industrial sorting system developed using **Siemens TIA Portal, Factory I/O, and S7-PLCSIM**.

The system sorts objects according to height and includes conveyor control, sensor processing, counters, emergency handling, alarms, and operator controls.

**Key technologies:** PLC • Ladder Logic • Siemens TIA Portal • Factory I/O • S7-PLCSIM

[View Project](https://github.com/zyadkhalafamen/plc-height-sorting-system)
